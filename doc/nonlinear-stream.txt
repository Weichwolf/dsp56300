Continuous nonlinear feedback bank

Original useful work

The fourth default bench scenario processes 204 channels at 48 kHz through four
cascaded driven feedback stages. Each stage uses y[n] = Q(SM(g*x[n] + f*y[n-1])),
with exact guest MPY then MACR and word-quantized state. The gains are 3/4, 7/8,
5/8, 15/16; feedback is 5/8, -1/4, 3/4, -3/8. The old state is read before its
replacement, and each quantized stage output feeds the following stage. This
models nonlinear driven filtering; it is not a device/firmware implementation.

Every frame reads a deterministic changing 32-frame input ring, processes all
channels, updates all 816 histories and writes an output ring. Distinct initial
histories, positive and negative feedback, both clipping signs, rounding ties and
ordinary results participate. Registers, histories, rings and loop frames remain
live across host calls and input seconds. No host state restoration, replay of a
completed program, or padding instructions are used.

Per channel: input load, coefficient-base assignment, four six-instruction stages
and output store =27 instructions /28 documented base cycles. Frame control is
seven instructions /15 base cycles. Total per frame is 5515 instructions /5727
base cycles; 48000 frames are 264720000 instructions /274896000 base cycles,
99.9622% of the 275 MHz reference. A 205th whole channel exceeds that cycle
budget. These are functional base costs, not complete pipeline/bus timing.

The full fixture runs 96000 frames. The bench naturally warms the first 48000 and
measures the next 48000 in the same instance, in 750 blocks of 64 frames. Each
block represents 1.333 ms of input and retires 352960 instructions /366528 base
cycles, reported separately from wall/process CPU. All final
registers, every P/X/Y word, stack frames, progress and interrupt/debug boundary
are compared with independent expectations outside the measured region.

The active data include 26112 bytes of input, 3264 history, 4096 output and 32
coefficients, plus the count store/guards. The finite caller-owned buffer spans
include unused gaps as well. Native code/page storage is reported separately.
These sizes alone do not establish complete cache locality or energy savings.

Independent expectations

The producer links only fixture-format code. It uses signed numerical products,
quotient/remainder rounding, after-rounding limiting and scaled/clipped word
outputs. The declared coefficient/input range proves MPY never limits and the
raw MACR sum stays strictly inside +/-2^48. Within this domain a signed 48-bit
clamp equals the qualified three-bit saturation rule; positive rounded limiting
clears the entire low24 word, independently of scaling.

Ordinary N/Z/E/U/V and sticky L are derived from the limited stored result.
Transfer growth S observes its own two numerical growth bits; word clipping
sets L independently. The initial numerical model confused those two effects;
a crosscheck against an independent raw56 instruction/transfer model exposed
and corrected it before fixtures were accepted. No emulator execution supplies
producer expectations. The crosscheck covers nine input/history boundaries,
all four coefficient pairs, six scaling/RM choices and clear/set old CCR bits.

The full two-second recurrence contains 719973 positive limiting events, 719973
negative limiting events, 76896054 canonical results and 9531168 rounding ties.
The two limiting signs and canonical population are required before writing the
full fixture. The check archive has 48 cases: 1/7/33/257 frames, six scaling/RM
choices and old CCR 0/255. Complete-state checks pass through reference/cached/JIT
with 1345 assertions per build. Both archives regenerate deterministically.
All 49 preexisting archives and their producer sources stay unchanged.

The shared bench supports nonlinear selection through its existing case/backend/
regex controls. Instrumented runs qualify state in report-only mode. Optimized
runs enforce every selected one-second package. Short fixture execution is
correctness/API evidence, not a throughput benchmark. Broader domains, sustained
latency/energy/cache, full ISA and all numerical modes remain active work.

Current optimized qualification

Both 126-test release/strict suites pass, all 24 full workload/backend states
agree and both new archives regenerate. The production baseline already passes
this new seconds package at about 296 MIPS in the matched capture. Extending the
generic RAM-region proof to pre-use R constants reduces nonlinear CPU demand by
30.40%, with the same program/inputs/coefficients/channels and guest work. The
candidate measures 0.622187..0.623368 CPU s per input second, 424.67..425.48 MIPS.
All compared packages pass. The two baseline captures retain six/five late
blocks; all candidate blocks pass. Separate default nonlinear bench: 0.624891
wall /0.624924 CPU s, 423.63 MIPS, maximum 1.009 ms /1.333 ms, zero late blocks.
All other default scenarios also pass, with spectral lowest at 330.66 MIPS.

These observations qualify this nonlinear stream, not arbitrary SM programs or
indefinite realtime. The numerical-domain and guest-state checks are separate
from the host memory proof. See native-constants.txt for guards, complete
cross-workload comparisons and increased cache-miss counts despite reduced
host instructions/loads. Energy and complete cache locality are not established.
