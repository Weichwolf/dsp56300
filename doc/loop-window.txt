Read-only proofs for bounded RAM loop windows

Scope and representation

An already admitted helper-free RAM loop can prove its complete invocation's
address window before entering the body. Successful proof removes repeated
R/M/N address guards. Failure preserves the original per-header guards and
partial execution; it does not reject an otherwise executable whole call.
The planner, ISA admission, arithmetic, canonical state and public layouts are
unchanged. The private automatic/disabled control permits same-build comparison.
Only packed/coalesced regions with 1..256 instructions are eligible.

Resource                     Representation / obligation
existing RSP+0..3 padding     private dword proved iteration count
existing RSP+4 padding       private byte success flag, initialized to zero
Cpu / NativeContext / API    unchanged; no additional architectural field
LC at each header           retain LC>1 before every prefix, even after proof
saved target / budget       retain every original ending/backedge check
R/M/N                       read once for a proved complete window
failed proof                original read-only per-header address guards
A/B, SR, X/Y, old inputs     existing formats and publication checkpoints

The setup uses the existing eight bytes of private SysV stack padding. A guarded
body cannot call a helper; MAC batching cannot coexist with this region's minimum
eight transfers. No admitted body can overwrite the proof flag. The first
ordinary residency preflight remains intact, and root/word facts remain empty.

Count and address proof

Let b be the number of instructions in a body and let

  n = min(floor(context.budget / b), LC - 1).

Require LC>2 and budget>=2*b before unsigned dword DIV, then require/prove n>=2.
EDX is zero and b is a nonzero bounded constant, so division cannot trap or
overflow. Guard failure changes only private scratch. The retained budget,
LC and saved-frame target checks can stop execution before n iterations. The
LC>1 test is essential: the LC=1 cleanup still belongs to general execution.

For a nonconstant monotone linear cursor, the existing planner supplies:

  U = unit updates per body
  S = post-N updates per body
  A = maximum post-N steps before an access
  L = min(bound_i - unit_steps_before_i).

The emitted unsigned64 comparison proves

  R + (n-1)*U + ((n-1)*S + A)*N < L.

Independent maxima conservatively cover all mixed accesses and both RAM banks.
Every updated cursor retains the compiled low16 M check. A nonzero N coefficient
also requires N<2^23. At most two transfers occur per instruction and n*b<=budget;
the coefficients are at most twice the dword budget. Their products and sum fit
64 bits, including raw dword LC/budget inputs. A wrap before another admitted
access fails the widened proof; final post-update wrap is permitted when safe.
Rejection retains original guards, including cases that execute a safe prefix.

A pre-use R constant is reassigned before the first access every iteration, so
the one-body proof suffices. A held cursor also needs only the one-body proof.
Simple unit modulo cursors retain the complete-ring guard: aligned base,
R in [base,base+M], entire ring below the RAM bound. A +1 step preserves that
ring for arbitrary repetitions. Post-N modulo, unknown modes, N/M writes and
later R assignments retain the established planner/general fallback. Constants
and final post-N exceptions are not extended to unproved repeating cursors.

Setup and every rejection are read-only for registers, RAM, counters and context.
Existing canonical exits, exact retirement/move/cycle prefixes, memory aliases,
P invalidation, callbacks, faults and interrupt/reentry contracts remain intact.
The optimization changes guard frequency, not fixed-point or flag semantics.

Independent qualification

The test-only RX wrapper emits the identical production proof and executes it
through the production SysV entry bridge. Expected safety comes from declared
instruction/port traces and an independent forward AGU model, not execution by
the emulator. Every success/rejection compares every Cpu/NativeContext byte.
Literal DIV bytes and empty/oversized IR rejection are also checked.

There are 41 declared profiles: 40 admitted planner shapes and one explicit
paired modulo-ring fallback when the full ring exceeds the smaller bank.
Patterns include unit, post-N, mixed, held, pre-use constants, final post-N,
paired X/Y and one cursor alternating X/Y with unequal bank bounds. Unit and
post-N variants cover all eight R/N/M fields; inactive fields carry invalid
canaries. The finite matrix includes 17 initial cursors, 11 strides, seven LC
values, seven budgets, matching/mismatching modifiers, high aliases, word/dword
limits and modulo sizes 2,3,4,6,8,16,32,64,128. Repeated R states let the forward
model prove huge invariant rings without artificial iteration limits.

The expanded independent complete-state RX accounting matrix adds a disabled
window control beside automatic, word/range controls and three residency formats.
It preserves all six scaling/RM modes, SM clear/set, all CCR, old parallel inputs,
aliases, P wrap, exact prefixes, LC/target/budget failures, 64-bit progress wrap,
I/O/P-edit/fault/IRQ/reentry and helper-clobber witnesses. Guest archives and
producers remain unchanged. This is compiler qualification, not complete ISA.
