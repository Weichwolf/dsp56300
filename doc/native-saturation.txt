Native arithmetic saturation (selected independently qualified domains)

Scope and state placement

This extends the independent general SM arithmetic described in saturation.txt.
It adds no DSP operation, public option, canonical field or runtime dependency.
An SM whitelist intersects existing native admission. Parallel ADD/SUB/ADC/SBC,
signed ordinary MPY/MAC and rounded variants, CLR/ABS/NEG/RND, transfer bypasses,
pure supported parallel moves and immediate ADD/SUB can lower. IFcc/.U, Tcc,
extended products, INC/DEC and control/count forms keep their existing general
implementation. CMP, ASR and all previously unqualified SM operations remain
explicit general diagnostics. SC/SA/DM/reserved scales remain excluded. NOP keeps
its existing bypass. The whitelist is not a claim of full numerical-mode coverage.

State                       Host holder             Invariant
rounded raw56 result        RAX, aligned56-in64      limiter follows rounding
raw overflow or limiting    R10D, Boolean            OR limiting into existing OF
raw 56-bit carry            EDX when live           limiter does not clobber it
three decision bits         RAX[63,56,55]            ignore all middle EXT bits
limiting constants          R8/R11, scratch          rounded positive clears low24
committed A/B               RBP/RBX                  retain dirty-value checkpoints
status                      existing SR/R14 path     derive E/U/N/Z from stored value
old parallel inputs         existing XMM snapshots   keep pre-transfer operands
PC/progress/frames/RAM       existing contracts       exact at every exit or observer

The current limiter evaluates the three-bit decision and both limiting constants
with scalar x64 scratch registers and conditional moves. It adds limiting to the
raw overflow Boolean, preserving carry and all other live holders. Existing
flag planning may omit overwritten result flags, but never an intermediate
sticky-L event. CLR needs no limiter; TFR/MOVE retain their distinct semantics.
SM-clear code emits none of the limiting instructions. Native MAC batches still
reject SM: a saturation after each sum changes the recurrence, so regrouped
products are not automatically equivalent. Branch-skip lowering remains an
unmeasured alternative, not a claimed improvement or adaptive selection policy.

Independent validation

The new test executes the actual RX generated bytes with every helper replaced
by a forbidden-call probe. Its raw-width action-table and arithmetic expectations
are shared with the independent fixture producer, not generated by an emulator.
All 256 parallel ALU bytes are classified for each of six scaling/RM modes.
The 182 lowered arithmetic/bypass forms run all 256 old CCR bytes against four
operand patterns and rotating full-width boundaries; the other 74 retain
full general execution. Every ordinary signed multiply/MAC encoding participates.
The byte classification is native admission, not an ISA-validity classification.

Separate traces cover every EXT byte, both MSP signs/destinations, rounding,
raw56 overflow/carry and noncanonical middle EXT values. Short and long immediate
ADD/SUB cover both destinations, five immediate boundaries, nine raw56 boundaries
and every CCR. Eight-operation mixed sequences exercise held status, dead-result
flag elimination, sticky L, packed progress, dirty A/B and repeated loop headers.
Both progress lanes wrap through their 64-bit boundary independently.

Public-Core tests run every prefix of a complete three-iteration SM DO program
through reference, cached and JIT backends, block limits 1/4/64, plus a disabled
optimizer. Independent full registers include the real DO stack pushes, every
loop count and the final general stack cleanup. Warm short budgets may encounter
an already larger cached block and use more general instructions. Exact total
accounting is required for those prefixes; complete loops and singleton blocks
must execute native arithmetic except DO setup and the final guarded cleanup.
The initial overly strict prefix counter expectation is retained in private logs;
it was corrected without removing any state/progress check or stimulus.

Existing SM callback, old-operand, aliased X/Y, same-PC, P-edit/fail-stop and
budget-prefix tests now additionally require native SM execution. Their previous
successful arithmetic/transfer expectations remain identical. All 49 binary
fixture archives and all producer sources remain unchanged in this increment.
Full ISA, other numerical modes and SM forms, sustained SM streams, additional
application domains, adaptive allocation, SIMD/multicore, latency/cache/energy
and transparent consumer integration remain part of the active objective.

unknown roots and explicit helper/observer erasure. Proved signed48 values omit
the limiter; signed50 values use an equivalent canonical clamp, preserving raw,
rounding and changed-value events independently. Rounded comparison still uses
the full positive48 maximum. Wide/unknown EXT gaps retain the general table.

for exact scope, continuous CPU reductions and mixed cache effects. Full SM/ISA
