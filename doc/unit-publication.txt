Native scalar-unit publication

InstructionPublication::unit_updates includes automatic-R, MOVE and ALU results
and adds native bit, control-byte and explicit address-calculation results.
Previous publication policies retain their original CPU result boundaries.
A unit_update effect carries UnitWriteback with RegisterUnit, the actual opcode and
up to three masked RegisterUpdates in storage/index order. Coordinates match
public unshifted Registers. Memory address/space/value fields are unused here.
The public effect layout requires a matching library/caller rebuild.

Actual native writes record first-written prior bits and genuine final values,
including unchanged destinations. No register diff or consumer CPU evaluator
creates the result. Bit register destinations retain their native storage-view
masks. Carry is separate from a modified SR operand; SR bit modification does
not invent a second carry write. Accumulator-read S/L masks describe actual set
paths, including already sticky bits. Multiple writes merge first provenance.

SSH bit modification targets the existing stack entry high word and does not
push or pop. SSH bit tests/branch reads retain the native pop of SP/SC. A native
source pop or limiting result publishes before a subsequent PCU branch/call,
including a later stack refusal. Low RAM bit operations use genuine owned reads
and native modified-word writes (TEST only reads). Accepted reads survive replay
and checkpoints without being sampled again. Only the upper peripheral window
uses atomic Io::bit. This transport correction applies to every publication
policy; a refused RAM read/write or peripheral bit operation preserves earlier
accepted automatic-R results without carry publication. Selected CPU effects
are not peripheral acknowledgements.

ANDI/ORI expose their actual eight-bit SR/OMR field, including unchanged writes.
LRA/LUA expose the native explicit register destination after genuine relative,
linear, modulo, multiple-wrap or reverse address computation. These are distinct
from automatic pointer publication. No descriptor supplies a computed CPU value.

The accepted native journal retains ordered CPU/external prefixes. Checkpoints
copy native unit context, pending results and accepted effects; restore rejects
abandoned tickets and requires caller-matched RAM/Io state. Reset cancels pending
CPU continuation. PC, progress and hidden retirement remain separately held.

Qualification passes 257730 directed assertions per profile under ASan/UBSan
and separate TSan. All twelve selected regression groups pass, including all
180600 cases in four complete unchanged owned archives through three staged
backend options. Expected faults retain their original fault/progress/processing/
debug oracle; full final fault register/memory equality is not newly asserted.
Each profile binds 92 C++ contexts, 69 CPU archive members, the instrumented
fixture-format dependency and ten protected executables. Zero own compiler,
tidy, format or sanitizer findings; no skipped cases or fuzzing. Initial compiler
and RAM transport failures remain retained failures, not retroactive passes.

Independent raw-register/per-bit models and literal address results cover native
writer masks, source/PCU failures and unchanged writes. Checkpoint controls include
342 RAM and 36 peripheral cuts across every backend pair. RAM clear/set/change
use distinct real reads/writes; TEST only reads. Real refusals retain accepted
prefixes, and restored execution never repeats accepted bus transactions.

This is single-instruction native value ownership, not calibrated silicon write
enables or physical pipeline phases. Native PCU/hidden-retirement ownership,
automatic stack extension/error interrupts, genuine per-stage operand/product
latches, forwarding, bounded multiple-inflight execution/annul/checkpoints,
cache/IRQ/RMW clocks, native staged JIT, sustained realtime and complete consumer
migration remain required. No firmware/application programs, physical device
traffic or automatic fuzzing are used. The complete objective remains open.
