Native ALU result publication

InstructionPublication::alu_updates includes the existing automatic-R and MOVE
policies and additionally exposes native data-ALU/BFU results and conditional
register transfers before PCU retirement. The previous policies are unchanged.
EffectKind::alu_update carries AluWriteback with the actual captured opcode and
at most three masked RegisterUpdates, in storage/index order. The memory
space/address/value fields are unused for this CPU result boundary.

Native write sites record actual destination and flag masks, even when their
values are unchanged. First-written bits retain their native pre-write value;
later writes to that same field merge provenance without replacing that prefix.
Final values come from the actual native computation. This is not a register
value diff, an opcode-descriptor evaluator or a host-provided CPU result.

Covered native paths: parallel arithmetic/logic/transfers/products, immediate
arithmetic/logic, scalar and register-controlled shifts, extended products,
INC/DEC/CMPU, DIV/NORM/NORMF, bitfield extraction/insertion/MERGE/CLB and Tcc.
A comparison produces flags without an invented data destination. False
conditional paths produce no writer. IFcc without U suppresses the restored SR
write; NORM/NORMF suppress restored carry. A native NORM data/R/CCR result remains
one owned value result. R/N/M automatic addressing and explicit MOVE producers
remain separate. Source-limiting S/L flags remain actual MOVE effects.

RegisterUpdate coordinates match public Registers, including unshifted raw A/B.
Main-word logic and logical shifts retain outer accumulator bits. Full arithmetic
and BFU accumulator results retain their native whole destination. Sticky L is a
writer only on an actual set path, including a set of an already sticky bit.
These masks describe native result storage; they do not establish silicon lane
write enables, forwarding rules, physical resource conflicts or clock phases.

The accepted ordered effect journal publishes only genuine admitted masks. PC,
loop/REP/vector continuation and retirement counters remain held separately.
Checkpoints include the pending result and accepted prefix; restored tickets
invalidate abandoned owners. A later native fault retains earlier accepted CPU
and external effects. Recalculation consumes retained genuine inputs/responses,
not another callback or a consumer register patch. Original parallel ALU operands
remain original latches after early source-register MOVEs become visible.

Publication still owns one instruction and uses the general executor, including
JIT options. It is not calibrated EX2 timing or overlapping execution. PCU and
control-byte/bit-operation effects, explicit AGU calculations and hidden
retirement changes are not silently relabeled as ALU results. Complete native
unit phases, physical RMW/cache/IRQ clocks, per-stage input/product latches,
forwarding, multiple-inflight execution/cancellation/checkpoints, native staged
JIT and sustained realtime remain required integration work.

Native begin_fetch additionally owns genuine opcode/extension Io reads, their
24-bit wrapping, refused-read faults and REP opcode-latch reuse. The archive
frontend supplies owned RAM and advances these real native fetch tickets rather
than preempting the CPU's missing-extension behavior. The complete-word capture
interface remains strict; opcode-only IRQ eligibility is a separate metadata
query. Logical fetch ownership does not establish physical fetch/cache timing.

Qualification: 437568 directed native ALU assertions per profile under ASan/UBSan
and separate TSan; logical program reads pass 1503 directed assertions.
All seventeen selected regression groups pass, including all 466152 cases in
eleven complete unchanged owned archives through all three staged backend
options and six affected legacy groups. Expected faults retain the archives'
original fault/progress contract; final register/memory equality for those fault
records is not newly asserted. Both profiles bind 87 C++ contexts, all 68 CPU
archive members, the instrumented fixture-format dependency and nine protected
executables. Zero own compiler/tidy/format or sanitizer findings; no skips/fuzz.
The initial archive-frontend and compiler failures remain retained failures.

The literal/model tests check native masks, full numeric/CCR state, equal writes,
conditional suppression, source replacement, NORM's companion R result, late
loop-stack failure and restore.
A separate staged fixture runner checks independent full register/memory state
for nonfaulting cases and retains the original fault/progress contract for fault
records. Per-result ownership consistency supports the independent numeric oracle.
No firmware/application programs, physical devices or automatic fuzzing are used.
No full numerical-mode/encoding/ISA or instrument equivalence claim follows.
