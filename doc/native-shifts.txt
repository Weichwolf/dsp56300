Native ASR and data-register transfers

The x64 emitter now lowers the single-bit parallel ASR A/B forms and register
moves among X0/X1/Y0/Y1/A/B. These remove general execution from common FFT
instructions and permit longer native-only regions. General execution remains
available; this is not full ISA or full-program qualification.

Arithmetic precision and flags

DSP accumulators use raw 56-bit coordinates externally and left-aligned host
values internally. ASR emits signed SAR by nine followed by SHL by eight. The
first shift places original DSP bit zero in x64 CF, which is captured before
the alignment shift. All internal padding bits are zero again afterwards.
This implements signed floor division by two, including negative odd values,
with sign extension, shifted-out Carry and cleared Overflow. Existing scaled
E/U/N/Z generation and sticky S/L preservation are reused. ASR declares its
Carry write to the flag-liveness pass so a subsequent ADC/SBC reads fresh C.

Only single-bit ASR is added to native lowering. Multi-bit immediate/register
ASR, ASL, logical/rotate forms and unqualified numerical modes retain their
existing general paths/diagnostics. The mode key and numeric guard remain
unchanged. The manual basis is DSP56300FM Rev.5, ASR pages 13-16/13-17; local
reference copies are ignored assets.

Register transfers and observability

A separate host-independent register plan admits all 36 source/destination
combinations among X0/X1/Y0/Y1/A/B. It excludes partial accumulators, R/N and
PCU/control registers and non-register move classes. Parallel duplicate
accumulator destinations remain outside the native transfer plan, following
the register-MOVE restrictions in pages 13-115/13-116. Excluded forms use the
existing general transfer/execution path; no new hardware behavior is invented.

Full accumulator reads reuse native word-transfer scaling, clipping and sticky
S/L logic. Full accumulator destinations receive the same sign-extended word
as general MOVE. A/B-to-A/B therefore transfers a bus word, not a raw 56-bit
copy. Both self transfers and other aliases preserve that distinction.
Old-input analysis captures every bank overwritten by a move but read by its
parallel ALU. The ALU consumes those old values after the move commits; source
clipping flags remain preserved. ASR's old-input description names only its
accumulator rather than conservatively snapshotting every bank.

Admitted data-register moves cannot fault, call I/O, invalidate P or change
control state. They do not require the memory-transfer dirty check, helper
checkpoint or unconditional flag-observation barrier. Flag liveness crosses
these pure transfers while retaining Carry dependencies and sticky effects.
Register-only native regions can derive common retirement from R15D instead
of maintaining a pending helper pair. Possible memory/general transfers still
materialize canonical progress, SR and accumulators before observers; loop
guards and exits retain their existing checkpoints. CPU/owner/runtime layouts,
public API, memory ownership and instruction budgets are unchanged.

JitStatistics.native_move_instructions already counts any complete parallel
transfer executed natively, overlapping native_alu_instructions. It now also
counts admitted register moves. It is neither an extra retired instruction nor
a count of memory bus accesses.

Independent evidence

native-shift-boundaries performs 6758417 directed assertions. Single shifts
cover both destinations, all 256 initial CCR bytes, six supported numeric
specializations, boundary values and every raw bit position/complement. The
model uses signed quotient/remainder floor division and independent raw-56
flags, not the emitted padding/CF technique. Complete six-instruction chains
exercise every admitted register pair with four parallel-ALU shapes, six seeds
and every initial CCR/mode. Native and disabled-optimization paths must expose
identical independently expected full registers and exact progress. Successful
native chains require exactly six native retirements, one native transfer and
zero general helper retirements, not merely Backend::jit selection.

The expanded native-retirement test performs 104795 directed assertions. It
adds ASR-to-ADC/SBC chains, one/four-op native loops and actual ASR prefixes
before accepted/rejected/SIMD-clobbering I/O callbacks and P invalidation.
Qword/PC wrap, exact budgets, LC/SP/saved-target guards and zero/partial exits
remain covered. General-helper admission negatives now use still-general ASL.
Dataflow tests retain real general partial-register witnesses while requiring
the newly admitted full-register forms to use native transfers. Existing binary
archives remain independent expectations and are not regenerated from core output.

Both complete suites pass all 97 tests without skips: release 133.47 s and
strict 435.83 s. All 102 project C++ translation units carry the required
nonrecovering sanitizer flags in strict builds. All 136 project C++ source/header
files pass formatting; quality policies, public API and CPU/owner layouts are
unchanged. The 40 public binary archives remain byte-identical to the parent.
The structural ISA audit passes; the complete-ISA gate deliberately still fails
with 118 partial catalogue entries and zero complete entries.
