Objective audit: incomplete

Build/setup: C++23, CMake/Ninja, LLVM19, inherited strict diagnostics,
clang-format/clang-tidy and ASan/UBSan setup. Release and strict builds/tests pass
for the current instruction and binary fixtures, including REP base-cost checks.
The strict executable runs with ASan/UBSan and additional integer/conversion checks.

Independence: production/test targets contain only this project's own DSP
implementation and compiler/standard-library facilities. No external DSP core
or JIT library is built or linked. Neighbor checkouts remain read-only.

Framework: caller-owned P/X/Y spans, architectural register view, left-aligned
A/B, synchronous I/O, explicit faults, individual instruction execution and a
paged decoded-word cache. Optional MemoryArena reserves complete address
spaces without touching cold RAM pages.

ISA: partial. Selected multiply/MAC, add/subtract, logical/unary operations,
parallel moves, AGU paths, basic control, DO/REP and admitted interrupts have
initial code. Coded forms are not all qualified. Independent tests currently
cover the manual MAC example, old-register latching on a parallel move,
REP/LC restore and fail-stop diagnostics through all three execution paths.
3369 synthetic binary cases independently cover all eight signed product input
pairs with MPY/MAC sign/accumulation variants, A/B destinations, ABS/NEG and
internal transfer sources, ADC/SBC carry and RND ties. They cover all three
scaling modes and both rounding modes where relevant. Cases compare
complete visible register and memory state, progress and interrupt admission.
The expectation generator does not link or execute the emulator; generated
bytes must match the checked-in fixture. Host-sequence tests also cover a
latched REP body after a P-memory write, sequential REP interrupt exclusion
and rejection of a control-flow body. Broader move, AGU, loop and interrupt
expectations remain required. See doc/fixtures.txt for format and local assets.

Bit/integer instruction extension: single-bit and immediate/register-controlled
ASL/ASR and LSL/LSR, ROL/ROR, shifted ADDL/ADDR/SUBL/SUBR, and CMPM now have
implementations. 4175 additional synthetic binary cases pass all three backends in
release and ASan/UBSan builds, with byte-for-byte regeneration. A separate
finite-width bit model generates directed binary
expectations for both accumulators, zero and boundary shift counts, aliased
control/source registers, discarded bits, intermediate sign changes, scaling
flags and preserved state. Defined shifts use constant-time host operations;
out-of-range counts and currently unsupported numerical modes fault explicitly.
REP can execute these single-word shifts and reevaluates register shift counts.
The model uses wrapped 56-bit magnitudes for CMPM; its minimum-negative corner
still needs independent hardware qualification. No hardware reference was used.

Conditional/immediate extension: Jcc/JScc, BRA/BSR/Bcc/BScc (short, long,
register-relative), Tcc and IFcc/IFcc.U now execute alongside short/long
immediate ADD/SUB/CMP/AND/OR/EOR. 38035 new binary cases pass release and
ASan/UBSan execution with exact fixture regeneration. Independent truth-table fixtures cover all
16 conditions and all 128 combinations of the seven relevant flags. They
check always-updated jump address registers, return frames, signed/wrapping
displacements, internal full-width transfers, conditional CCR preservation,
partial logical writes, immediate sign extension and numerical flags. Directed
sequences also check real subroutine returns and condition reevaluation in REP.
Parallel encodings have a statically checked disjoint fast decode before the
more specific rules. This does not establish complete control/interrupt timing.

Local source-built workload qualification: 512 binary fixtures for the ordinary
and wide/rounded Blofeld sixteen-sample filter routines pass all three backends in
release and ASan/UBSan builds. Directed inputs cover both RM values, in-place
and separate output, signed corners and limiting. Independent integer recurrence
expectations check complete visible state/memory and instruction base costs.
Manufacturer program bytes, preparation/analysis and fixture manifests remain
ignored. These direct-core cases do not qualify coefficient preparation,
arbitrary aliases, interrupted calls, continuous streams or complete device
execution.

Additional complete LP12 workload qualification: 2400 local source-built calls
pass all three backends in release and ASan/UBSan builds. Independent equations
prepare coefficients from directed cutoff/resonance and synthetic curve pairs,
then evaluate the fixed-point recurrence. Cases include both RM choices, linear
modifiers, N0=1/3, negative damping, the cutoff-dependent floor, the strict wide
branch and equality at its boundary. Poisoned initial coefficient scratch,
all visible registers and RAM, exact output/history words, original return,
instruction counts and estimated base costs match. Other coefficient callbacks,
arbitrary entry modes, interrupted calls and device behavior remain unqualified.

Modes: ordinary 24-bit arithmetic, three defined transfer-scaling modes and
two rounding choices have initial code. Compatibility, double precision,
sixteen-bit arithmetic and arithmetic saturation reject at parallel execution;
these required modes remain to be implemented and tested.

Timing: documented base costs are being added for implemented forms. Pipeline
interlocks, IRQ entry/return qualification, exact event admission and external
waits remain open. A complete checkpoint API is pending; Registers omits hidden
REP/interrupt continuation. Instruction budgets now have identical guest
retirement semantics on all backends; failed DO cleanup does not consume
instructions or base cycles. Host callback execution/reset/register/interrupt
reentry is rejected while memory access and P invalidation remain permitted.

Performance: a binary-fixture replay benchmark now provides a warm scalar
reference/cached baseline for the qualified source-built Blofeld filters.
One DSP instance per backend, host restoration outside the execution timer,
64 warmups and a median/range of nine 4096-call trials. Complete results are
checked after warmup and each trial. This measures initialized call replay,
including timer/retirement-check overhead; it is not continuous audio or device
performance. An initial independent scalar x64 JIT now emits unrounded MPY/MAC,
CLR/ABS/NEG/TFR and NOP, with guarded general helpers for other operations and
parallel memory moves. It has exact budgets, numerical mode keys, deferred P
invalidation, bounded executable storage and immutable RX mappings. Shared
fixtures cover all three backends; host tests check ABI/boundary behavior and
native/helper counters expose actual lowered execution. See doc/jit.txt for
instrumentation scope and remaining native work. All nine CTests pass in release
and strict builds, including exact fixture regeneration. SIMD is not implemented.
Earlier isolated arithmetic experiments do not establish emulator speed.
More source-built workloads, register-bank SIMD
measurements, guarded independent-voice batching and code/cache evidence remain
required before a final performance claim.

Measured native improvement: on four directed ordinary/wide filter and complete
LP12 cases, the first scalar JIT reduces warm execution medians by 23-24%
relative to cached execution in the same release binary on the i5-10400.
Three runs per case use the replay protocol above; compare the median of run
medians. The published executable working set is 16-20 KiB for these cases.
Native ALU still calls parallel-move helpers, and cold compilation is excluded.
These measurements qualify those initialized calls only. Exact local inputs,
artifact hashes and raw measurements remain in ignored workload/analysis files.

Measured scalar improvement: parallel instructions with a zero ALU byte now
execute their move without saving unused ALU inputs or calling the no-op ALU
dispatcher. All nonzero ALU forms retain the general path. Full synthetic and
local Blofeld fixture checks pass in release/strict builds. Three alternating
before/after measurements on two directed Blofeld filter cases reduce cached
execution medians by approximately 9% (ordinary) and 7% (wide/rounded) on the
i5-10400. This is a warm-call comparison on those cases, not a whole-device or
final-core performance result.

Integration: basic header/library target and memory/I/O contract exist.
Installed package consumption and integration fixtures remain pending.
The complete objective remains active. No full ISA/device/performance claim
follows from the narrow initial checks.
