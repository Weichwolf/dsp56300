Continuous spectral analysis

An original streaming workload performs periodic-Hann windowing, scaled 1024-point
complex FFT, natural-order permutation and mean I/Q power for fifteen 48 kHz
streams. A 480-sample hop gives exactly 100 analysis steps per input second.
Fifteen is the largest whole stream count below the 275 MHz reference budget.
Work is useful spectral analysis; no NOPs fill the remaining capacity.

Initialize 544 zero-history words followed by two input seconds per channel.
The DSP advances its saved input cursors by 480 each hop, sharing one complex
FFT workspace and coefficient table across streams. A sixteen-spectrum output
ring retains power blocks. All histories, ring positions and loop frames
continue through one natural warmup second and the next measured second.

input/history         X/Y arrays, saved channel cursors   continuous tone/dither phases

progress              remaining hop count in X:25         no host state restoration

Window body: load Hann into Y1, paired X0/Y0 input, two MPYs, two RNDs, paired
A/B store (seven instructions/sample). Rewind the advanced R0 by 1024-480=544,
not by the hop itself, before saving the next overlapping-window cursor.
Power body: paired complex load, MPY real square, MAC imaginary square, ASR A,
RND A, store. Division by two supplies complex full-scale headroom.

R3/R7 walk input-cursor metadata; N7 holds 200 outer hops. The FFT uses the
remaining address/offset registers and restores reverse-carry modifiers before
power output. M1=16383 wraps the power ring; scratch/output FFT addresses stay
inside its first enclosing span and therefore behave linearly there. The ring
and metadata must not alias the FFT workspace, window or input streams.

Refactor the existing integer FFT oracle into a reusable header and permit
relocating the own FFT program. All existing fixtures must regenerate unchanged.
The new producer must not link or execute the emulator. Check complete registers,
all RAM/guards, inactive residual frames and exact retirement/base-cycle counts.
Short 1/2/3-hop cases exercise initial history, its replacement and output wrap,
both RM settings and incoming C/S/L. Keep clipping/DFT qualification in the broad
existing FFT cases; the stream uses explicitly bounded low-amplitude inputs.

Time 100 ten-millisecond input hops after natural warmup in the same DSP instance.
Retain all deadline failures, process CPU and worst hop latency. This is CPU
spectral work, not a peripheral, bus/pipeline timing or energy measurement.

Implemented calibration and oracle evidence

The DSP program retires 2567045 instructions / 2661611 base cycles per hop,
or 256704500 / 266161100 per measured input second (96.7859% reference load).
A sixteenth stream would require 283905100 base cycles/s. The full two-second
case adds the outer DO and totals 513409001 instructions / 532322205 cycles.
There is no host restoration between its 100 warmup and 100 measured hops.

The shared FFT program accepts a relocation entry; its default entry preserves
the existing 112 FFT fixtures byte-for-byte. Its integer oracle is extracted
unchanged into fft_model.hpp. The stream producer links the fixture codec only.
All architectural expectations are integer-exact. A separate complex DFT checks
eight bins per selected window, including each stream's tone and sidebands;
the DFT is a bounded mathematical check, not the source of serialized states.

Twelve short cases cover 1/2/3 hops, both RM modes and incoming zero or C/S/L.
One hop retains fifteen spectra; two wrap the sixteen-spectrum power ring;
three replace the initial 544-word history completely. Every window is checked
for bounded components and absence of new clipping/growth. The short producer
passes 738000 assertions, 2880 DFT/power-bin probes and 3264918 FFT rounding ties.
Maximum direct DFT discrepancy is 3.2793 word units; mean-power discrepancy is
0.479911 units, below the declared 32/4 bounds. The full producer passes 6147045
assertions, 360 direct probes and 11779579 ties, with maxima 1.51844 / 0.479911.
The exact integer primary expectations have no tolerance in emulator comparisons.

Complete expected state includes all 16 stack entries. Slots1/2 retain the hop
entry, slots3/4 the last channel-loop entry and preceding-hop flags, slots5/6
the last power-loop entry and FFT status, and slots7/8 the last nested FFT-group
entry. Reverse-carry M0/M4 return to linear; M1 remains the power-ring modifier.
Input cursor metadata advances by exactly 96000 words in the full case. X0 and
X:25 report one remaining hop at the finite outer ending; SP/SC and outer LA/LC
restore their initial values. All P/X/Y, including guards and untouched regions,
are compared. Only terminal ring contents survive; short cases cover earlier
history/output boundaries. A complete-output trace is not implemented.

Measured initial production JIT

Two sequential same-affinity runs after targeted checks give 1.185048..1.194156
wall seconds and 1.182036..1.188717 process-CPU seconds per input second,
214.97..216.62 actual guest MIPS. Every measured hop misses its 10 ms budget.
This is a retained performance failure. Generated storage is 303104 page-rounded
bytes; one extra finite-cleanup block compiles during the measured interval and
its cost is included. Runtime counters report 244221099 native ALU retirements,
12483401 helper retirements, 61437099 native moves and zero MAC/AVX2 batches.
These counters classify retirements, not all calls inside native move lowering.

The FFT program contains 4092 pure address updates per transform, 6138000 per
input second, plus many immediate address/offset setups. These are promising
general lowering candidates, not measured speedups. Their register/dataflow,
modulo, flags, budget and fallback obligations need independent qualification.
FIR and IIR remain separate gates; no aggregate can hide either slow workload.

Final qualification

All 113 correctness tests pass in release (106.46 s) and strict ASan/UBSan
(233.92 s), with no skips. The complete 200-hop stream independently matches all
six release variants. Instrumented bench passes all three full-state/report-only
scenarios. These comparison runs overlap correctness jobs and do not replace
the controlled sequential production timings above. The optimized default bench
retains FIR PASS, IIR FAIL and spectral FAIL; no slow scenario is omitted.
All 46 earlier binary archives are unchanged, including the default-entry FFT.
All 118 strict C++ units retain nonrecovering checks and all 160 C++ files pass
format/tidy/Werror policies. No fuzzing was run. There are now 48 archives.
The structural ISA audit passes; its complete gate still fails with 118 partial
rows and none complete. Full ISA, all applications, throughput/CPU improvements,
SIMD/multicore research and energy qualification remain mandatory open work.
