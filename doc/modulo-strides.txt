Ordinary-modulo positive block strides

For normal modulo, the documented special displacement P*2^k uses a positive
integer P. At the one-block boundary of a power-of-two modulus, the original
positive Nn advances or retreats one aligned block according to the addressing
mode. A negative Nn of the same magnitude stays on the ordinary ring path.
Preserve the original operand sign before applying addressing +/-; this applies
to pure AGU, LUA and indexed or short/long displaced X/Y MOVE. Displaced MOVE
uses its encoded displacement, not the unrelated Nn register. Linear and
multiple-wrap modes retain their separate behavior. No public API/layout,
peripheral, pipeline, clock or error-response contract changes.

The independent codec-only producer generates 8896 pure AGU/LUA cases, 768
indexed X/Y loads/stores and 1536 short/long displaced loads/stores. Distinct
values at the old and correct addresses expose wrong effective-address reads
and writes. The finite controls cover all eight index registers, SM off/on,
positive/negative operands, aligned block boundaries, 24-bit address wrap and
linear/multiple-wrap controls. All 11200 complete numerical snapshots agree
with the reset-isolated vendor software reference before candidate execution.
The published baseline disagrees in 3264 cases; these represent one defect,
not 3264 independent implementation bugs. Manufacturer programs are absent.

The mathematical producer is linked only to the fixture codec. Its C++ output
is byte-identical to separately authored Python/vendor-qualified goldens in
both sanitizer profiles. Existing address archives retain every input, program
and count while correcting 1632 expected R/N register states. Seven former SM
refusal cases keep their original inputs and now use independently calculated
success expectations. Canonical-Mn software-reference controls qualify those
seven numerical results; reserved Mn high bits in existing public inputs remain
an existing project convention, not a new vendor or physical-hardware claim.
Two region/accounting I/O tests now follow the already documented failed-read
contract: preserve the destination, retain the prefix and fault, execute no ALU,
retire nothing and never replay. The prior published library fails their old
expectations too; no production I/O behavior was changed to make a test pass.

Reproduce after building with the strict/thread presets:
  ctest --test-dir build/strict -R '^modulo-strides-' --output-on-failure
  ctest --test-dir build/thread -R '^modulo-strides-' --output-on-failure
See modulo-strides-reference.json for exact hashes and scoped evidence.

This qualifies finite mathematical/common-CPU domains. Unpredictable ordinary
modulo offsets, reserved fields, debugger-seeded hidden loop/exception state,
stack extensions, chip-specific pipelines and timing still require independent
adjudication. The old vendor simulator is not a physical chip oracle. All 118
ISA rows and the complete objective remain partial; no fuzzing or physical
traffic was used.
