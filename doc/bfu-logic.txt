Logical BFU operations with arithmetic saturation enabled

Scope and admission

Ordinary 56-bit operation now admits SM for parallel AND/OR/EOR/NOT, single-bit
LSL/LSR/ROL/ROR, short/long immediate AND/OR/EOR and multi-bit immediate/register
LSL/LSR. These operations use the Bit Field Unit and bypass arithmetic saturation.
The existing raw logical algorithms are unchanged; only their explicit numerical
admission expands. Other numerical modes and reserved scaling still reject.
Unqualified CMP/TST and shifted arithmetic are not included in this whitelist.
Native SM admission is unchanged: these new domains use general helpers with
canonical checkpoints. No public layout, memory/event/I/O or code-cache contract
changes, no new host instruction set and no peripheral behavior are introduced.

Primary source: DSP56300FM Rev.5 sections 3.1.5/3.2.3, logical instruction pages
and tables, with reference copies/extracts kept private:
https://www.nxp.com/docs/en/reference-manual/DSP56300FM.pdf
The BFU classification and SM exclusion must be read together. This follows the
previous normalization review rather than applying a numerical 48-bit clamp to
all operations performed while SM is set.

Standalone logical shift counts use low5 control bits and admit 0..24. The six
old control sources include A1/B1 destination aliases. Rotates are single-bit
through Carry. Counts 25..31 retain explicit software diagnostics, not claimed
physical hardware traps. The manual's immediate-field range note and 24-bit
operation description still require hardware/errata confirmation for complete
qualification. SB/SC/DM, full numerical combinations, every transfer/alias,
physical flags, IRQ and calibrated pipeline/bus timing remain open. All affected
ISA rows stay partial.

Independent original binary fixtures

A codec-only generator produces bfu-logic-sm.d56 (57696 cases) and
bfu-shifts-sm.d56 (18968),76664 total. The 65536-case format bound is unchanged.
Neither the producer nor the expectation code links or executes the emulator.
The oracle evaluates each word bit through an explicit truth table or one-bit
serial shifter, then reconstructs all 56 bits individually. This differs from the
core's host-word masks, shifts and bulk Boolean operations. Source/control field
coordinates and opcode shapes are independently declared.

The 26 parallel logical shapes cover three binary functions/four sources/both
destinations plus NOT A/B. Eight parallel shift/rotate shapes cover both
destinations/directions. All old CCR bytes and six scaling/RM combinations are
explicit for each parallel shape. Separate walking-bit/complement matrices cover
all 56 raw positions and preserve outer-word canaries. Equal/complementary/zero/
all-one operand pairs force zero/sign outcomes for every logical source and
destination. Short/long immediates cover field/sign boundaries. Every defined
logical count, all six controls, ignored high bits and self-aliases are tested.

Conditional matrices cover all 16 predicates/all 256 CCRs for a representative OR
and every logical shape with selected flags, both flag-publication choices.
Shift/rotate conditionals also test all predicates and both choices. Original
parallel X0 loads overwrite a prospective source before the ALU but expectations
use the captured old X0. REP matrices include every exact partial prefix,
word/Carry feedback and current alias-count reevaluation. DO matrices include
final/continuing iterations, saved LF/FV choices and wrapping stack coordinates.
These finite matrices are not exhaustive legal operand/state combinations.

Legacy stimuli and diagnostics

Only four old records change across two archives, with byte-identical initial
registers/program/data/budgets. Bit-operations ordinal 4161 (immediate LSL zero)
and test-complement ordinals 45977/46484 (NOT A/B) become successes. Bit-operations
ordinal 4163 retains its original X0 low 5 bits = 27 and changes from unsupported-SM to
a diagnostic for count 27. It is not forced into a valid count or counted as a success.
The generator's initial undefined-count stop exposed this distinction before
writing a fixture. Every unrelated serialized record and the other 52 old
archives remain byte-identical. No input case or quality check is dropped.

Public-Core boundaries

A separate host target passes 2472 checks through reference/cached/JIT, optimizer
on/off and block limits 1/64. It checks every native/general prefix, exact words/
base cycles/dispatch counts, complete registers, real native/helper counters,
same-PC ordinary/SM alternation and undefined counts. SC/SA/DM/reserved scaling
and parallel/immediate CMP remain rejected. Synchronous I/O observes the exact
canonical native prefix, then accepts/rejects a parallel load, optionally edits
the suffix in P, and verifies old versus current source use. Partial writes,
PC/progress and fail-stop retries are explicit. Expected results come from the
independent truth/serial models, not agreement among shared executors.

The new microfixtures establish mode accuracy, not continuous BFU throughput.
The full objective still requires complete ISA/modes/IRQ/pipeline/timing,
adaptive native allocation, broader continuous applications, SIMD/multicore,
integration, sustained realtime/reserve and cache/energy qualification.


Verification and measurement scope

sweeps pass 143/144 each (114.11/265.60 s), failing only the old host expectation
that NOT with SM must reject. That same original input is corrected to exact
raw-result/flag success plus following-NOP progress. Only that test module is
rebuilt; targeted runs pass 9786 assertions in 0.28/1.17 s. Other 143green targets
and production are unchanged, so they are not repeated. Both initial failure
logs and the focused passes remain. No claim of two new fully green sweeps.

All 56 archives reproduce exactly through 54 registrations. Per build the new
archives pass 1615489/531105 complete-state assertions across three backends and
the dedicated boundary target passes 2472 checks. Existing product/width/accounting/
SM witnesses remain green. All 158 strict C++ units retain required instrumentation;
all 201 source/header files pass formatting/tidy/Werror. All 24 release backend/
stream states and four strict full states agree. Concurrent strict timing retains
FIR/spectral package failures and 682/122/100/34 late blocks; it is correctness-only
scope. Structural ISA audit passes; require-complete fails with 118 partial entries.

Separate immutable baseline/candidate comparisons pass all 16 full states/packages/
block budgets with unchanged actual guest/native/helper/move/batch/AVX2 counts
and page storage. Final default seconds packages take 0.232148/0.466937/0.680423/
0.517324 s, all block budgets passing. FIR/spectral matched CPU increases 1.05%/
0.33%; no causal speed gain is claimed. The previous FFT 1.222611 s / 209.96 MIPS and
all old misses remain, not replaced by these passing captures. This does not
qualify continuous BFU capacity, indefinite realtime or the complete performance
objective. See continuous-bench.txt for PMU miss regressions and complete scope.
No fuzzing/publication; the full objective stays unchanged and incomplete.
