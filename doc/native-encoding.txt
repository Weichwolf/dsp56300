Compact x64 immediate encodings

Design recorded before implementation

Generic RAM/post-N regions reduce host work but grow native code and instruction
cache misses. Investigate actual machine-code layout/encoding with unchanged
DSP work, fixtures, register allocation, checkpoints and native/general paths.
The full objective remains incomplete. No DSP arithmetic SIMD or worker change.

Candidate                  Exact state requirement             Expected byte cost
32B entry/header alignment host NOPs, same branches/state      padding/entry work
unsigned 32-bit constant   complete qword, zero upper bits     MOV r32: 5/6 vs 10
signed 32-bit constant     complete sign-extended qword        MOV r64,imm32: 7 vs 10
other qword constant       exact arbitrary 64-bit pattern      existing MOVABS: 10
signed byte ALU operand    identical operand at selected width imm8 saves 3 bytes
accumulator immediate      same operation/flags, implicit AX   saves 1 byte
memory immediate           same width/address/flags            compact operand only

All MOV forms preserve host flags, including zero constants. Positive $80000000
and $ffffffff constants must zero-extend; negative sign-extended constants use
their full 64-bit value. A qword ALU immediate retains the prior sign-extension
of its 32-bit operand. A byte immediate represents the low eight bits. Word
immediates truncate to 16 bits and qualify for a sign-extended byte only when
that byte reproduces the complete word. Full-width word payloads have two
bytes. Byte/word encodings now have explicit directed witnesses; their former
unqualified wide payloads are not used by the existing DSP compiler paths.

The existing ModRM/SIB/displacement forms, memory bounds/alias proof, branch
labels/patching, numeric modes, loop guards, budget accounting and helper/return
checkpoints are unchanged. Recompute normal label offsets from emitted bytes;
never splice shorter instructions into already-patched machine code. No public
CPU, context, option, architecture or consumer contract changes.

Rejected alignment pilot

A private 32-byte experiment aligned guarded child entries and loop headers,
retaining the ordinary path. Twelve complete stream states pass. Parent/
aligned/aligned/parent captures use CPU2 and natural one-second warmup plus
one measured input second, with no build/test task from this repository.
Unrelated host load/frequency/scheduling remain uncontrolled.

FIR CPU changes 0.258323..0.259358 -> 0.254424..0.255991 s (1.40% lower), IIR
0.676639..0.678611 -> 0.681057..0.682066 s (0.58% higher), spectral
0.830145..0.841842 -> 0.834110..0.842277 s (0.26% higher). FIR's generated path
is unchanged, so its small timing change does not prove an alignment benefit.
Both aligned spectral packages fail their wall deadline (1.122212 / 1.595156 s),
with CPU still around 0.84 s; retain the substantial scheduling gap rather than
attributing it causally to padding. The parent packages pass. There is no
established cross-workload improvement, so this candidate is not retained.
All pilot logs, code diff and executables remain in ignored experiment storage.

Independent encoding qualification

A new directed test executes actual RX bytes through the production SysV bridge.
Literal bytes for positive/sign-extended/wide constants, imm8/imm32 boundaries,
accumulator and memory operations were checked separately with LLVM MC 19 during
authoring. That assembler is not a build/test/runtime dependency.

An independent serial carry circuit checks ADD/ADC/SUB/SBB/CMP arithmetic,
borrow, auxiliary carry and signed overflow for 8/16/32/64-bit operands. Separate
logical/parity/zero/sign expectations check OR/AND/XOR. Host AF is undefined
for logical operations and is excluded only there. All other defined arithmetic
flags are checked, with both incoming carry choices. MOV checks all six flags
unchanged, with distinct incoming combinations.

The matrix covers fifteen non-stack GPRs (including low-byte REX cases), signed
byte/word/dword/qword boundaries and high-half preservation/clearing. Memory
cases cover low/high/SIB bases, zero/127/128-byte displacements, unaligned words
and whole-buffer canaries. Compare complete qword results and all adjacent
bytes. The probes preserve DSP state and context. RSP is covered by a literal
memory encoding; it is deliberately not overwritten as a register destination.
The independent direct test passes 767401 assertions per build.

Both builds pass all 118 correctness tests, zero skips: release 124.43 s with
two CTest processes, strict 238.91 s with three. The direct host-encoding test
passes 767401 checks independently in each configuration. All eighteen full
stream/backend combinations match complete independent state; those loaded-host
timings are correctness evidence only. Strict bench checks all three full states
in report-only mode, retaining its wall deadline failures. All 48 archives are
byte-identical. All 130 strict C++ translation units retain nonrecovering required
instrumentation and all 168 C++ files pass format/tidy/Werror policies. Structural
ISA audit passes; complete-ISA remains red with 118 partial rows and zero complete.
No fuzzing or publication is performed. Green host encoding tests do not complete
DSP ISA, all applications, long-run realtime, cache locality, adaptive allocation,
SIMD/multicore lifting or energy goals.

Footprint and hardware counters

Page-rounded native storage changes IIR 53248 -> 49152 bytes (7.69% less) and
spectral 385024 -> 344064 bytes (10.64% less). FIR stays 32768 bytes; page
quantization can hide smaller individual encodings. The number of DSP operations
and chosen execution routes does not change. This improves host code footprint,
without adding DSP arithmetic SIMD, workers or speculative memory effects.

Four additional alternating PMU runs per IIR/spectral scenario use the same
CPU affinity and binary pair. All state checks pass, every event runs for 100%
of enabled time. User counters cover the whole process, including fixture setup,
oracle, cold compilation, natural warmup, measured work and final validation.
Do not attribute them exclusively to JIT execution/the measured interval, or
infer energy use from them.
