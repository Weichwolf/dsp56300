Signed-width certificates in the native compiler

Scope and abstract state

The native compiler tracks conservative signed widths for A/B within each emitted
body. Width zero means exactly zero; width w in 1..56 contains the signed range
[-2^(w-1),2^(w-1)-1]. Both roots start at unknown 56-bit width. There are no sampled values,
profile guesses or loop induction assumptions. Repeated headers are safe because
unknown 56-bit width contains every next-iteration value. Tail/recompiled entries start anew.
A private disabled mode preserves the general native emitter in the same build.
No public CPU/context/API layout, guest instruction/cycle count or numerical
mode admission changes. Unknown forms/modes retain existing general execution.

Effect                       Conservative fact / obligation
full A/B bus-word write      signed24 <<24, at most 48 bits
TFR full accumulator         old source width; explicit SM bypass
pure signed24 product        magnitude <=2^47, width49, no raw56 overflow
MAC                           max(49,oldWidth+1); overflow possible only above56
ADD/SUB/ADC/SBC/CMP            max+1; sound zero/negation/carry cases
ABS/NEG                       width+1 unless zero; MIN56 remains unproved
single ASR                   max(1,w-1), zero stays zero; no raw overflow
RND/rounded product          conservative widening; unknown 56-bit width may round-overflow
SM result width<=48          cannot limit
SM result width<=50          exact signed48 clamp, with distinct rounded constant
wider/unknown SM result      original three-bit decision table, never guessed clamp
helper/observer/unknown       discard both facts; observer resets before AND after

Product magnitude bounds tighten MAC beyond adding a generic signed49 operand:
a canonical 48-bit accumulator plus the actual product fits 49 bits, rounding may need 50 bits.
The analysis snapshots old widths before parallel moves, applies bus writes,
then updates the arithmetic destination. CMP keeps the post-move stored bank;
its flags describe the computed comparison result. Pure moves/opaque effects
are separate. Observable transfer helpers cannot leak optimistic facts onward.
Current independently bounded arithmetic, such as a pure product, can still
use its own local certificate after a successful transfer.

Saturation proof

SM is not a general numeric signed48 clamp for arbitrary extension bytes. The
qualified table observes exactly EXT7, EXT0 and MSP23. A signed50 interval restricts
EXT to00/01/FE/FF: in that domain the table equals signed48 saturation. Wider
values such as positive EXT7E can remain unchanged and must use the general table.
This property is derived from the existing manufacturer model, not a new ISA
interpretation. Rounded positive limiting keeps its fixed low24-cleared constant,
independent of scaling. The upper comparison uses the full positive48 maximum,
so an unlimited rounded value above the rounded saturation constant is preserved.

The canonical emitter preserves the old result, performs signed positive/negative
comparisons and conditional moves, then detects an actual changed value. Raw
and rounding overflow remain independent sticky events. A proved result that cannot limit
emits no limiter. No runtime bound branch is added: facts follow from
supported instruction semantics, and unproved cases retain general emission.

Flag publication

Impossible raw/rounding overflow need no SETO/merge work. When no ALU overflow,
rounding or limiting event can occur, sticky-L bookkeeping is omitted; prior L/S
remain. Scaled/clipped transfers still produce their own original S/L effects.
A live V still clears when false. Carry is captured before any scratch XOR or
limiter comparison can alter host flags and is never inferred from signed width.
For final width<=integer-position+1, E is false; width<=position makes U true.
Zero domains give Z=1/N=0. Other result flags retain their original computation.

The existing liveness boundaries remain: transfer observers, ending guards,
helpers, returns, faults, code invalidation and admitted interrupts receive exact
canonical state. Eliminated dead flags cannot become observable before their
replacement. Retirement, native-move counts, PC/AGU/loop state and checkpoint
positions are unchanged. These are compiler facts, not DSP-time shortcuts.

Independent witnesses

The new metadata test passes 8018957 assertions per build. It constructs all 57
width classes through independent raw56 one-bit shifts/zero operations, probes
boundary/extension-gap values with six scaling/RM choices, all 128 ordinary signed
multiply/MAC encodings, arithmetic/unary/TFR variants, carry effects and both SM
settings. Every returned width contains independently computed raw results; any
omitted event must be absent. Canonical clamp equals the separate three-bit action
model, including rounded constants. Constant bit/sign/zero/-1 values exercise
short/long immediate and compare retention. Explicit helper/observer erasure,
full-word conversion and old parallel wide-A/new-word-A distinctions are checked.
These are finite declared matrices, not full encoding or hardware qualification.

The expanded helper-forbidden RX/Core accounting matrix passes 2597667 checks per
build with automatic/disabled range analysis and all three residency controls.
Actual emitted execution compares independent complete registers/RAM/flags/costs,
aliases/P wrap, all CCR bytes/modes, partial budgets/LC/targets, callbacks/P edits,
rejected loads, fail-stop, fast-vector service and reentry. All existing 5120088
native SM checks remain. The producer/expectation models never execute the DSP
to obtain expected numerical results. All 52 guest archives/producers remain
byte-identical; no manufacturer/application program or other emulator is used.
