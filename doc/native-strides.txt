Linear post-N RAM regions

Design and scope

Extend the existing generic guarded-RAM planner to linear (Rn)+Nn transfers.
This admits address-heavy native traces without recognizing any application,
FFT opcode sequence, fixture or host-provided N profile. Numeric admission,
contiguous PC/loop metadata, minimum eight real RAM transfers, no R/N/M writes,
no P-alias stores and the ordinary fallback remain required. Nonlinear post-N
addressing remains on the existing ordinary/general path.

State              Entry/body representation              Checkpoint
R and M             canonical CPU words; low16 M profile    every body and return
N                    canonical CPU word; no assignments     dynamically read
unit/N access counts compile-time monotone coefficients     immutable per trace
A/B and old inputs   existing GPR/XMM dataflow snapshots     same ordered operands
status/progress      existing liveness/packed retirement    canonical at every exit
RAM                  original transfer capture/commit       X before Y; no reordering

For each R bank record U, the number of preceding unit increments, and K, the
number of preceding post-N updates. Retain L = min(bound_at_access - U), with
zero for impossible unit offsets, and Kmax = max(K_at_access). For reused N,
require raw N < 2^23 and evaluate entry_R + Kmax*N < L in 64 bits. Nonnegative
N and monotone U/K make this sufficient for all accesses; independent extrema
can conservatively reject some safe traces with different span bounds. No
speculative RAM read is needed to make this decision. A failing proof selects
ordinary execution before effects.

If a post-N update has no later access through the same R, its result need not
stay inside RAM, and N needs no range restriction. Emit the normal modulo-2^24
result, including negative N, wrap and raw high bits. A following loop header
rechecks the new R before its first effect. Every post-N result is masked to
24 bits. A reused negative/large N, changed M, invalid R, exhausted loop or
unproved address mode retains exact fallback. Existing unit-step and ordinary
unit-ring proofs are unchanged.

Qualification and performance

The existing native-ram-regions test now covers six independent trace shapes:
unit steps, linear post-N, mixed unit/N, Y post-N and terminal X/Y post-N.
Actual guarded RX bytes are checked through the production calling convention
against independent address, register and ordered ALU/transfer models. Both
physically separate and shared X/Y backing storage are included, with equal
128-word and unequal 96/120-word declared spans. Complete backing arrays are
compared, including words beyond the declared RAM limits.

Directed matrices retain every initial CCR byte and six supported scaling/RM
modes, changed/high M, positive/zero/negative and raw high-bit N, near-boundary
R, loop capacities/last cleanup and header rejection after completed bodies.
The existing qword progress-wrap and private exclusion checks remain. Warm
Core budgets expose every 0..18-instruction prefix, and same-PC changes in N
exercise both the proved and ordinary route without stale addresses. Existing
I/O callbacks, P invalidation, rejected-transfer partial state and interrupt
boundary witnesses remain part of the same test. Static admission explicitly
rejects nonlinear post-N profiles, including power-of-two and ordinary rings.
These original tests use no manufacturer program or another emulator's output.

All 1269134 directed checks pass independently in release and strict builds.
The full 117-test sweeps pass in release (99.69 s, two CTest processes) and
strict (231.81 s, three), with no skips. All 18 complete-stream/backend pairs
match independent state; their loaded-host timings qualify correctness only.
The instrumented bench validates all three full states in report-only mode.
All 48 archives remain byte-identical, all 128 strict C++ units retain required
nonrecovering sanitizer flags, and all 167 C++ files pass format/tidy/Werror.
Structural ISA audit passes; complete-ISA remains red with all 118 rows partial.
No fuzzing or publication is performed. No full-ISA,
cache-locality, long-running hard-realtime, multicore/SIMD or energy completion
claim follows from this address-proof increment.

11.90%); FIR/IIR remain 32768 / 53248. The guarded variant and ordinary fallback
both remain available. Future layout/sharing/register-placement experiments
must weigh hot working-set cost, not just throughput or page-rounded storage.

running for 100% of enabled time. All states pass. Scope is the whole process,
including setup/oracle, cold compilation, warmup, measured execution and checks;
