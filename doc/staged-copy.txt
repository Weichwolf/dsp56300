Staged effect transfer cost

The owned-effect path keeps the existing guards, effects, faults, timing units,
publication order and bounded storage. Read-only owner dispatch borrows its
InstructionEffect. advance_instruction borrows the selected pending value and
copies it once into the immutable accepted log. Resumption uses that stable log
entry because recomputation replaces pending. No reference escapes a call.
Public SDK headers, checkpoint layout, instruction semantics and JIT admission
are unchanged. The existing by-value sample handoff is retained: LLVM already
lowers it as a tail jump without an extra copy.

LLVM19 optimized x64 output removes the additional 664-byte memcpy before each
advance. Its explicit stack reservation falls from 1368 to 40 bytes; the required
accepted-log copy remains. This is a compiler/code-shape observation, not a
throughput factor or instrument realtime qualification.

  build/release/dsp56300_external_run_bench image-add captured-pcu 32

The existing external-Io benchmark now uses the automatic backend and accepts
1..256 repetitions (default 1). It retains all/selected workload and mode reporting.
Each repetition runs the same independently checked 4096-instruction CPU fixture.
Reported instructions, real P reads and time are sums of these intervals. Core
construction, program setup and independent arithmetic/bit expectations are
outside timing; the first staged allocation inside each interval is included.
These audio-MAC, image-add and communications-XOR microfixtures diagnose host
API/fallback cost. They do not synthesize sound or qualify continuous throughput.

Focused checks cover staged read/write/bit/reset refusal, every publication
family, original operand ordering, mutated caller observations, bounded plans,
loop/IRQ/debug events, candidate/ordinary checkpoints, cross-backend restoration,
exact budgets and the literal rounded-product boundary. Release and ASan/UBSan
and separate TSan qualify the same source. No full-suite or fuzz run is implied.

The ALU host matrix retains every previous input. Its old blanket SM rejection
for TST/compare/MAX/MAXM is replaced by the already qualified independent numeric
expectations (vendor-differential.txt). Two reserved scaling combinations add
real pre-publication refusal controls. No production numerical modes are added.

staged-copy-reference.json records artifacts, actual component results and the
paired old/new measurement scope. Full ISA, physical timing and connected
instrument correctness/performance remain open.

The recorded ten fresh-process, alternating old/new runs use one CPU affinity
and identical benchmark/fixture objects, with both workspace native queues
held and no workspace compiler/worker before or after each child. Uncached
staged median old/new ratios are 1.056/1.038/1.074 for the three domains.
Captured-PCU ratios are 1.001/0.992/1.139; the image case's small regression
and broad overlapping variation remain in the reference. Ordinary synchronous
controls range from 0.984 to 1.057. Host activity/frequency are not controlled.
These noisy component observations do not establish a universal speedup.
